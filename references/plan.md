# 方案设计 · 栏目、首屏与风格

## 定位公式

> 为【谁】，通过【什么方式】，解决【什么问题】，交付【什么结果】。

写不成一句话，说明业务还没收敛，先帮用户收敛，再谈页面。

## 栏目库（按需选，不强制）

| 栏目 | 什么时候需要 | 内容要点 |
|---|---|---|
| 首屏 | 必有 | 是谁、帮谁、解决什么、一个主按钮 |
| 服务 / 课程 | 必有 | 人群 + 问题 + 交付物 + 方式 + 如何开始 |
| 关于我 | 服务型个人站必有 | 真实经历、方法、为什么做这件事 |
| 真实作品 / 案例 | 有真实素材才放 | 背景—做法—结果，附授权状态 |
| 学员 / 客户评价 | 有授权才放 | 原话 + 身份（可匿名） |
| 资质 / 证书 | 有才放 | 名称、机构、年份，逐字核对 |
| 工作流程 | 咨询、教练、定制服务适合 | 从接触到交付的 3–5 步 |
| 常见问题 | 有高频疑问时 | 价格、周期、适合谁、不适合谁 |
| 内容 / 文章 | 知识服务者适合 | 真实发布过的内容，不放空链接 |
| 预约 / 联系 | 必有 | 真实可用的联系方式或预约入口 |
| 资源下载 | 有真实文件才放 | 文件确实存在、可下载 |
| 团队 | 用户主动要求才放 | 每位成员信息需本人确认 |

**不要默认加**：荣誉墙、合作伙伴 Logo 墙、倒计时、滚动数字、"10000+ 学员"。

## 按业务选结构

- **一对一服务（教练 / 咨询 / 私教）**：首屏 → 擅长问题 → 服务方式与流程 → 关于我 → 案例（匿名）→ 预约。
- **课程型（老师 / 工作室）**：首屏 → 课程体系 → 老师介绍 → 试听 / 报名流程 → 真实成果 → 联系。
- **知识服务（博主 / 顾问）**：首屏 → 我能帮你什么 → 内容 / 作品 → 关于 → 合作方式 → 联系。
- **专业服务（法律 / 财务 / 设计）**：首屏 → 服务范围 → 资历 → 案例 → 流程 → 联系；避免承诺性表述。

## 首屏写法

- **主标题**：一句具体的话。用"帮谁 + 解决什么"，不用标语。
  - 好：`帮 30+ 的职场人，把英语重新用起来`
  - 差：`赋能每一个渴望成长的你`
- **副标题**：方法、资历或差异化，1–2 句，必须有依据。
- **主按钮**：只留一个主要动作（加微信 / 预约 / 看课程），其余做成文字链接。
- **信任元素**：真实年限、真实资质、真实作品缩略图。没有就不放。

## 风格方向（给用户选，不锁死）

- **A. 温和专业**：米白 / 暖灰底，深色正文，衬线标题，留白多。适合咨询、教练、教育。
- **B. 明亮亲和**：浅色底，圆角卡片，一个明快点缀色。适合亲子、语言、兴趣课程。
- **C. 沉稳克制**：高对比，无衬线，信息密度稍高，动效少。适合专业服务、B 端合作。
- **D. 按参考复刻气质**：只提取配色关系、版式节奏和字体气质，不复制对方的图片、文案和品牌元素。

## 方案输出要求

- 控制在半屏内，用户能一眼看完并做决定。
- 栏目后面写一句"为什么需要"，方便用户删改。
- 风格给具体描述，不只写"简约大气"。
- 待补材料写清"缺了会影响哪一块"，并说明能否先做简版。
