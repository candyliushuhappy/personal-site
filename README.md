# personal-site · 个人官网建站 Skill

把老师、教练、咨询师和知识服务者的真实经历与服务，整理成一个可预览、可迭代的个人官网。

这是一个给 Claude Code / Claude 使用的 Skill：**分轮收集资料 → 给出方案并等待确认 → 生成可预览网页 → 交付验收清单**。不套模板、不编造、不做假按钮。

## 适合谁

- 老师、教练、咨询师、私教
- 知识博主、独立顾问、自由职业者
- 想把简历 / 服务介绍 / 作品集变成一个真正能打开的个人网站的人
- 需要给客户、合作方、学员一个稳定介绍入口的人

## 它能做什么

- 用自然语言分轮了解你的业务、素材和风格偏好
- 给出定位、栏目、首屏文案方向、联系按钮和视觉风格方案
- 在你确认方案后，生成移动端优先、可预览的网页
- 只使用你提供或明确授权的文字、照片、案例和联系方式
- 交付时列出已实现内容、待补资料、未验证部分和上线步骤

它不做这些：不虚构经历和评价，不套用他人素材，不做假表单 / 假二维码 / 假链接，不擅自发布到外部平台。

## 使用流程

1. **收集**：名称、服务、目标受众、网站目标、可公开的联系方式
2. **方案**：定位、访客、栏目、首屏方向、联系按钮、视觉风格、待补材料
3. **确认**：你确认或修改后，才进入生成
4. **生成**：首屏 → 服务 → 真实作品 / 案例 → 关于 → 联系
5. **交付**：预览方式、已实现、待补、未验证、上线验收清单

## 设计原则

1. **不虚构**：姓名、头衔、数据、评价、案例、资质、照片、联系方式都要有依据。
2. **不套模板**：栏目按业务选，不强制团队、案例、荣誉墙。
3. **先方案后施工**：确认方案后才生成网页。
4. **真按钮**：每个按钮都指向真实目标；没有就隐藏或标"待补充"。
5. **移动端优先**：手机可读、可点，再考虑桌面。
6. **交付实际网页**：能建就建；不能建就如实说明，不谎称已生成。
7. **隐私与授权**：个人信息、儿童照片、客户案例公开前先确认授权。
8. **不擅自发布**：部署、域名、表单服务由用户操作或授权。

## 注意

- 生成的网页默认在本地预览；上线需要你自行部署或明确授权。
- 独立域名、表单提交、在线预约、支付等功能需要额外的账号或服务支持。
- 使用前请确认你对文字、照片、案例、证书等素材拥有公开授权。
- 本仓库不包含任何第三方图片、字体或课程素材。
