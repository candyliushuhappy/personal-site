# 分轮收集 · 提问脚本与授权

## 第一轮：核心信息（最多 5 问）

口语化地问，不要一次甩出问卷。

1. 我该怎么称呼你？个人名字或品牌名，网站上想用哪个？
2. 你是做什么的、主要服务哪类人？（例如：教成人口语、做职业咨询、带青少年编程）
3. 这个网站最想完成什么？是让人了解你，还是让人联系 / 预约 / 买课？（可多选）
4. 希望公开哪种联系方式？微信、手机、邮箱，还是预约链接？请给我准确内容。
5. 目标访客现在最困扰的一个问题是什么？

**收到这些就可以做简版。** 如果连联系方式都没有，先做展示页，联系区留"待补充"，并说明此时无法真正承接咨询。

## 第二轮：可信度素材（按需问，不重复第一轮）

- 有没有简历、个人介绍、课程介绍或服务清单？直接发文字或文件都行。
- 有哪些可以公开的照片？头像、工作照、课堂照、作品图。
- 有哪些真实的作品、案例或学员成果？每个案例能说清"背景—做法—结果"最好。
- 有没有学员 / 客户评价？是否获得对方授权？能否公开姓名？
- 有哪些证书、资质、从业年限？证书编号是否公开？
- 价格是否公开？如果不公开，写"详询"即可。

## 第三轮：风格偏好

- 你希望网站给人什么感觉？给三个形容词，或者说"像什么样的人"。
- 有没有喜欢的网站或图片？发链接 / 截图即可，只参考气质。
- 有没有品牌色、Logo、固定字体？没有就让助手给方向。
- 有没有明确不要的颜色、元素或语气？

## 提问原则

- 每轮最多 5 个问题，一轮问完等回答再继续。
- 用户已经说过的，不重复问。
- 用户发来简历 / 作品链接，先读，再只问缺的部分。
- 用户说"你看着办"时，给 2–3 个具体选项让他选，而不是空问。
- 信息足够就开始出方案，不要为了完整性无限追问。

## 授权确认（必须问，且要留下明确回答）

- **手机号 / 邮箱**："这个号码会公开显示在网站上，确定可以公开吗？"
- **微信**："微信 ID 会显示，是否同时需要二维码？二维码请发我原图。"
- **儿童信息**："涉及孩子的照片、姓名、作品，需要监护人同意。你确认已获得授权吗？没有授权我就不放。"
- **客户案例 / 评价**："案例和评价需要当事人同意。是否已授权？是否要匿名处理？"
- **证书 / 头衔**："证书和头衔会逐字展示，请确认名称与发证机构无误。"
- **地址**：默认不公开具体地址；只有用户明确要求且业务需要时才放，并建议只写到商圈级别。

## 资料不足时的处理

| 情况 | 处理 |
|---|---|
| 有名称、服务、联系方式 | 做简版：首屏 + 服务 + 关于 + 联系 |
| 缺照片 | 用排版和文字撑住，不放图库人物冒充本人 |
| 缺案例 / 评价 | 整块隐藏，不编造，不写"学员都说好" |
| 缺资质 | 不写年限和头衔，只写实际能证明的内容 |
| 缺价格 | 写"价格与安排请咨询"，或整块不写 |
| 缺风格偏好 | 给三个方向让用户选，不默认套模板 |

## 用户常见表达 → 实际需求

- "想让人加微信了解课程" → 联系按钮 = 微信复制 + 二维码（如有），页面重点在课程与信任。
- "给合作方看的" → 更重经历、案例、服务能力，联系方式可以更正式（邮箱 / 电话）。
- "先做个简单的" → 单页四块，不做多页导航。
- "要能预约" → 先问有没有真实预约链接或客服流程；没有就只做联系方式，不做假表单。
